Patti Veedu is a lightweight, high-performance web project showcasing the traditional village health foods of Tamil Nadu. This repository contains the source code for a responsive landing page built with zero dependencies, focusing on semantic HTML, modern CSS layouts, and smooth user experience.

🍽️ Featured Menu Highlights
Palaya Saadham: Probiotic-rich overnight fermented rice.

Cheese Masala Dosa: Golden-crisp fusion crepe with molten cheese.

Kozhukatta Pidi: Rustic hand-molded steamed rice dumplings.
